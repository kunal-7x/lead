# site-visit Runbook

Purpose: book, confirm, reschedule, track no-shows, and report site visits.

Dependencies: lead identity, calendar slots, notification, WhatsApp, analytics.

Paging signals: booking failure, double-booking, reminder failure, no-show spike.

Common fixes: verify slot inventory, replay confirmation event, send manual reminder, mark no-show follow-up.

Dashboards and logs: bookings, confirmations, attendance, no-shows, reminder delivery.

Rollback: deploy previous image and disable auto-confirm if slot consistency is at risk.
